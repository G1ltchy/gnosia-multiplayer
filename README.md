# GNOSIA 다중기기 진행 사이트

## 실행
1. Node.js 18 이상 설치
2. 이 폴더에서 터미널 실행
3. `npm install`
4. `npm start`
5. 같은 Wi-Fi의 친구들은 방장 컴퓨터의 IP 주소로 접속
   - 예: `http://192.168.0.15:3000`

## 포함 기능
- 방 생성 / 참가 코드
- 각자 휴대폰에서 비공개 역할 확인
- 역할 수 설정 및 무작위 배정
- 공개 투표 내역과 최대 3차 재투표
- 엔지니어 / 의사 / 수호천사 / AC주의자 / 버그 / 그노시아
- 밤 행동 처리
- 1:1 밀회 초대와 임시 채팅
- 게임 진행 기록
- 재접속 토큰

## 주의
- 메모리 기반 서버라 서버를 재시작하면 진행 중인 방이 사라집니다.
- 인터넷 배포 시 Render, Railway, Fly.io 같은 Node.js 호스팅을 사용할 수 있습니다.
- 팬 프로젝트용 프로토타입이며 원작 이미지·명칭의 배포 권리는 별도로 확인해야 합니다.
